TikTok Connection

Use TikTok's official authorization page. Your password should only be entered on TikTok, never into this dashboard.

Developer setup required

Before real login works, register an app in TikTok for Developers, configure its redirect URI, and request only the permissions your app needs.

  1. Register your app at developers.tiktok.com.
  2. Enable Login Kit and request approved scopes.
  3. Configure a HTTPS redirect URI on your backend.
  4. Complete TikTok review/approval where required.
  5. Implement OAuth code exchange on the server, not in this HTML.
